# Ghost in the Machine: Resurrecting Lost Languages with Grounded AI

*Submission for DEV Community Hacktoberfest 2026 — Week 4 Challenge*

---

## 1. What I Built
**Echoes of the Forgotten** is an interactive digital archaeology experience and retro terminal where forgotten programming languages and computing milestones speak once more. 

Users can summon the machine spirits of:
- **COBOL (1959)** — The stoic veteran powering global banking infrastructure.
- **FORTRAN (1957)** — The pioneer that proved optimizing compilers could outmatch hand-written assembly.
- **BASIC (1964)** — The democratic classroom language that launched the personal computing revolution.
- **Assembly (1947)** — The elemental bare-metal voice of opcodes and silicon registers.

Rather than being a simple chatbot, **Echoes of the Forgotten** is a full-stack, CPU-friendly Retrieval-Augmented Generation (RAG) platform that operates with zero GPU footprint and remains 100% functional even when offline!

---

## 2. Key Technical Innovations

### A. Zero GPU Footprint with Pure-Python BM25
As a student developing on a standard Windows laptop with no dedicated GPU, running local 8B models or vector databases with heavy PyTorch/CUDA dependencies was out of the question. 

Instead, I implemented a lightweight lexical retrieval engine powered by **BM25Okapi** (`rank-bm25`). The entire Python backend consumes less than 40 MB of disk space and executes document queries in under 5 milliseconds on a modest CPU.

### B. Anti-Hallucination & Verifiable Citations
Large language models notoriously hallucinate citation links and historical dates. In this project, citations are **never generated by the AI**. 

Instead:
1. The user's query is analyzed by the BM25 retrieval engine.
2. Verified archival passages (from the Computer History Museum, IEEE annals, and university archives) are retrieved.
3. System prompts strictly forbid the model from fabricating citations.
4. The backend injects real, verified source metadata directly into the frontend response.

### C. Offline Resiliency (Zero-Cost Operation)
The application defines a pluggable provider abstraction (`AIProviderBase`). If an API key is configured, it streams inference from open-weight **Meta Llama 3.1 8B Instant** on Groq's high-speed LPU infrastructure. 

If no API key is provided or the network is disconnected, the system automatically falls back to **Offline Archive Synthesis**, providing atmospheric, source-backed answers directly from the local knowledge base with zero external dependencies.

### D. Safe Retro Terminal Interpreter
The terminal includes a safe command interpreter supporting:
`help`, `whoami`, `list`, `switch <tech>`, `search <query>`, `inspect <doc_id>`, `clear`, and `exit`.
It uses pure-Python tokenization with strictly zero usage of `eval`, `exec`, or `subprocess`.

## 3. Technology Stack
- **Frontend:** React 18, Vite, TypeScript, Tailwind CSS, Lucide Icons.
- **Backend:** Python 3.14, FastAPI, Pydantic v2, rank-bm25, HTTPX, SQLite.
- **Testing:** pytest, pytest-asyncio, HTTPX ASGI test transport.
- **AI Model:** Meta Llama 3.1 8B Instant (Open Weights).
