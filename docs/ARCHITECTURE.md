# System Architecture — Echoes of the Forgotten

## 1. Overview
**Echoes of the Forgotten** is an interactive digital archaeology archive and retro terminal experience built for the DEV Community Hacktoberfest 2026 Week 4 challenge ("Ghost in the Machine").

The project resurrects forgotten programming languages and historic systems—**COBOL**, **FORTRAN**, **BASIC**, and **Assembly**—via an atmospheric terminal interface powered by open-weight AI retrieval-augmented generation (RAG).

## 2. Key Architectural Decisions

### A. Zero GPU Footprint (CPU-Friendly BM25 Retrieval)
- Instead of installing heavy PyTorch packages, CUDA runtime, or GPU-dependent vector databases, the application uses **BM25Okapi** lexical ranking (`rank-bm25`).
- The entire Python environment takes **< 40 MB** of disk space and executes queries in **under 5 milliseconds** on standard laptop CPUs.
- Avoids returning low-confidence documents by applying a minimum relevance threshold (`min_score=0.3`).

### B. Anti-Hallucination & Citation Integrity
- Language models are notorious for inventing plausible-sounding URLs and dates.
- In **Echoes of the Forgotten**, URLs and citations are **never generated by the AI model**. 
- The backend matches documents from verified historical repositories (Computer History Museum, ACM Digital Library, Dartmouth Archives, University of London), and attaches the real source URLs and dates directly to the response payload.

### C. Offline Resiliency (Zero-Cost Operation)
- If the student or judge does not possess an external API key, or if the external provider hits rate limits or network issues, the application automatically activates **Offline Archive Mode**.
- In offline mode, the engine uses local synthesis to present the exact verified excerpts from the historical archive, ensuring the application remains **100% useful and testable at zero cost**.

### D. Safe Terminal Command Execution
- The terminal implements an in-memory command interpreter supporting:
  - `help`: Lists commands.
  - `whoami`: Displays current machine spirit profile.
  - `list`: Lists available computing spirits.
  - `switch <tech>`: Switches character channel.
  - `search <query>`: Queries the BM25 knowledge base.
  - `inspect <doc_id>`: Displays complete raw archival record.
  - `clear`: Flushes buffer.
  - `exit`: Returns to directory.
- **Strictly zero usage of `eval`, `exec`, `subprocess`, or shell execution**. User input cannot escape the application container.
